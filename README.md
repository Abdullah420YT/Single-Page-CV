# Single-Page-CV

A simple, clean, and responsive single-page CV built using HTML and CSS.

## Project Description

This project is a single-page CV (Curriculum Vitae) designed to display personal information, skills, education, work experience, and social media profiles in an organized layout.

The design focuses on simplicity, readability, and responsive styling for different screen sizes.

## Features

- Personal information and contact details
- Skills section
- Education section
- Work experience section
- LinkedIn and GitHub profile links
- Simple and clean design
- Responsive layout for mobile devices

## Technologies Used

- HTML5
- CSS3

## Project Structure

Single-Page-CV/
│
├── index.html
├── style.css
└── README.md

## How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension in VS Code.
